# Discovera

AI 기반 부산 관광객 분산 추천 웹 앱입니다.

Discovera는 관광지별 혼잡도를 분석하고, 사용자의 취향과 이동 동선을 고려해 덜 붐비는 부산의 새로운 명소를 추천합니다. 방문 인증, 스탬프, 지역 상점 할인으로 관광객 분산과 지역경제 활성화를 연결합니다.

## 주요 기능

- 부산 16개 구·군, 32개 관광명소 실시간 혼잡도 지도
- 자연·산책 / 문화·전시 / 맛집·시장 테마별 AI 추천
- 맞춤 관광 코스, 방문 스탬프 및 지역 쿠폰
- 통신사 익명 유동인구, 교통·주차, 날씨·행사 데이터를 결합하는 실시간 데이터 연동 구조

## 실행

`index.html`을 웹 브라우저로 열면 실행됩니다. 지도 타일을 불러오기 위해 인터넷 연결이 필요합니다.

현재 혼잡도 값은 데모 데이터이며, 운영 환경에서는 `/api/crowd` API에 실제 익명 집계 데이터를 연결하도록 설계돼 있습니다.
